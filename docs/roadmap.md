# Math Game — roadmap

## Цель

Создать математический тренажёр и постепенно провести его через полную вертикаль:

`frontend → backend → база данных → deploy → домен`.

Jeff не обязан помнить весь синтаксис, но должен уметь показать работающий результат, объяснить путь данных и самостоятельно внести небольшое изменение.
