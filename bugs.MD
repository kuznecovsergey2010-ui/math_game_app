# Баг: после первого ответа игра проверяет не тот пример

Всё задание — это **4 маленьких шага**. Каждый шаг — это 1–4 строчки кода в файле `script.js`.
После каждого шага сохрани файл, обнови страницу в браузере (F5) и проверь, что написано в пункте «Проверь».

Весь код писать заново **не нужно**. Мы только добавляем несколько строчек в то, что уже есть.

## Чекпойнты: один шаг = один коммит

В конце каждого шага есть блок **Чекпойнт**. Дошёл до него и всё работает — делаешь коммит и пушишь. Так видно, где ты сейчас, и если что-то сломается, всегда можно вернуться к последнему рабочему коммиту.

Коммит делается тремя командами в консоли, в папке проекта:

```
git add script.js
git commit -m "текст коммита"
git push
```

Текст коммита для каждого шага уже написан в чекпойнте, его можно просто скопировать.

Перед коммитом полезно запустить `git status`. Он покажет, что изменился только `script.js`.

## Шаг 0. Посмотри на баг своими глазами

1. Открой `index.html` в браузере.
2. Нажми `начать`.
3. Реши пример, нажми `Отправить`.
4. Появился второй пример. Посмотри на страницу: **первый пример и первое поле ввода никуда не делись**.
5. Сделай так ещё пару раз — копий становится всё больше.
6. Обнови страницу. Теперь на первый пример ответь **неправильно**, а на второй — **правильно**. Игра всё равно напишет `Неправильно!`. Это и есть баг.

Почему это ломает игру: когда ты нажимаешь `Отправить`, код ищет поле ввода так:

```js
const windowInput = document.querySelector("input")
```

`querySelector` всегда находит **самое первое** поле на странице. То есть игра проверяет старое поле со старым примером, а не то, куда ты сейчас ввёл ответ.

**Идея исправления:** перед тем как показать новый пример, удалить старый. Тогда на странице всегда будет только одно поле, и код найдёт именно его.

## Шаг 1 (разминка). Исправь тип кнопки

Найди в функции `startPlay` строчку:

```js
submitButton.type = "text"
```

Замени `"text"` на `"button"`:

```js
submitButton.type = "button"
```

У кнопки не бывает типа `text`: этот тип есть у поля ввода, а у кнопки нет.

**Проверь:** игра работает так же, как раньше, и в консоли (F12 → Console) нет красных ошибок.

> **Чекпойнт 1**
> ```
> git add script.js
> git commit -m "Исправлен тип кнопки Отправить на button"
> git push
> ```

## Шаг 2. Дай примеру и кнопке имена (id)

Чтобы потом удалить пример и кнопку, их нужно как-то найти. Для этого дадим им `id`, так же, как уже сделано для скрытого ответа (`correctAnswerElement.id = "correct"`).

В функции `startPlay` найди место, где создаётся пример, и **добавь одну строчку** перед `append`:

```js
const newElement = document.createElement("p")
newElement.innerText = String(numbOne) + "+" + String(numbTwo) + "=?"
newElement.id = "example"          // <-- добавь эту строчку
bodyElement.append(newElement)
```

Там же найди, где создаётся кнопка `Отправить`, и **добавь одну строчку**:

```js
const submitButton = document.createElement("button")
submitButton.type = "button"
submitButton.innerText = "Отправить"
submitButton.onclick = checkAnswer
submitButton.id = "submit"         // <-- добавь эту строчку
bodyElement.append(submitButton)
```

**Проверь:** игра выглядит так же, как раньше, и ошибок в консоли нет. (Видимых изменений пока и не должно быть.)

> **Чекпойнт 2**
> ```
> git add script.js
> git commit -m "Добавлены id для примера и кнопки"
> git push
> ```

## Шаг 3. Удаляй старый пример перед новым (главное исправление)

В функции `checkAnswer` в самом конце есть строчка:

```js
startPlay(1)
```

Она создаёт новый пример. **Прямо перед ней** добавь 4 строчки, которые удаляют старый пример:

```js
document.getElementById("example").remove()   // удаляем текст примера
correct_way.remove()                          // удаляем скрытый правильный ответ
windowInput.remove()                          // удаляем старое поле ввода
document.getElementById("submit").remove()    // удаляем старую кнопку

startPlay(1)
```

`.remove()` значит «убрать этот элемент со страницы».

**Проверь:**
- после каждого ответа на странице только **один** пример, **одно** поле и **одна** кнопка;
- специально введи неправильный ответ в первом примере, а во втором правильный. Для второго должно быть написано `Правильно!`.

> **Чекпойнт 3**
> ```
> git add script.js
> git commit -m "Удаляется старый пример перед показом нового"
> git push
> ```

## Шаг 4. Пусть надпись «Правильно / Неправильно» будет одна

Сейчас надписи копятся: `Правильно!`, `Неправильно!`, `Правильно!`... Сделаем так, чтобы всегда была видна только последняя.

**4.1.** В `checkAnswer` дай надписям `id`. Добавь по одной строчке в каждый `if`:

```js
if (windowInput.value != correct_way.innerText) {
    const textLoose = document.createElement("h1")
    textLoose.innerText = "Неправильно!"
    textLoose.id = "result"            // <-- добавь
    bodyElement.append(textLoose)
}

if (windowInput.value === correct_way.innerText) {
    const textWinner = document.createElement("h1")
    textWinner.innerText = "Правильно!"
    textWinner.id = "result"           // <-- добавь
    bodyElement.append(textWinner)
}
```

**4.2.** В начале `checkAnswer`, сразу после строчки `const correct_way = ...`, удали старую надпись, если она есть:

```js
const oldResult = document.getElementById("result")
if (oldResult) {
    oldResult.remove()
}
```

`if (oldResult)` нужен потому, что при самом первом ответе старой надписи ещё нет, и удалять нечего.

**Проверь:** на странице всегда видна только одна надпись: `Правильно!` или `Неправильно!`.

> **Чекпойнт 4**
> ```
> git add script.js
> git commit -m "На странице показывается только одна надпись с результатом"
> git push
> ```
